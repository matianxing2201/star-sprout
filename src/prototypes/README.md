# 首页视觉方向原型（一次性代码）

> **这是一次探索，不是生产代码。** 它不写测试、不做错误处理、不抽公共层。
> 选定方向后，胜出的那一个会被**重写**进生产代码，其余连同这个目录一起丢弃。

## 它回答的问题

**「首页应该长什么样，才能不再一眼看上去像 AI 生成的？」**

现状的病因（实测）：全站只有一套表面配方（46 处「描边+投影+圆角」重复）、
版式是平的（188 处小字 vs 13 处大字）、模板化光斑、6 个常驻循环动画。
所以三个方向**不在颜色上分歧，而在结构上分歧**。

## 三个方向（分歧轴各不同）

| 键 | 方向 | 分歧轴 | 一句话 |
| --- | --- | --- | --- |
| `A` | 展览馆 | 版式与留白 | 超大展示字 + 单一强调色 + 每屏一个焦点，彻底不用卡片网格 |
| `B` | 立体书 | 材质与层叠 | 去掉实心描边，用层叠的半透明阴影表现纸的厚度；元素相互叠压、轻微旋转 |
| `C` | 游戏地图 | 信息结构 | 地图就是首页；没有「今日任务」区块，任务挂在地图节点上 |

外加一个参照项 `now` —— 就是现在线上的首页，方便你直接对比「到底治好了没有」。
它不是参赛者，只是基准。

## 怎么看

```bash
pnpm dev
```

然后打开首页，在地址后面加 `?variant=`：

- <http://localhost:5173/?variant=A>
- <http://localhost:5173/?variant=B>
- <http://localhost:5173/?variant=C>
- <http://localhost:5173/?variant=now> ← 现状，用来对比

底部会浮出一条深色胶囊：左右箭头切换（键盘 `←` `→` 也行），`↻` 重放入场动画。
不带 `?variant=` 时首页就是生产版本，什么都不变。

## 硬约束

- **不碰生产代码的形状**：变体只读 store 里的真实数据（同一个孩子、同一天、同一份地图），
  不新增 store、不改领域逻辑、不写持久化
- **每个变体都满足工艺底线**：入场 < 300ms、用 `ease-out`、只动 transform/opacity、
  每个可点元素有按压反馈、没有常驻循环动画（角色除外）—— 不能靠「执行差」来衬托方向
- **不进入生产包**：只通过动态导入引用，且被 `import.meta.env.DEV` 门控
  （`src/styles/design-contract.spec.ts` 里有契约守着）
