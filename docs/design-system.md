# 儿童视觉体系 · 动效体系 · 奖励体系

> 目标：**第一眼吸引孩子，第二眼让家长觉得专业。**
> 明确排除：廉价儿童网站、大面积彩虹色、过度卡通、PPT 风、成人 SaaS Dashboard。

---

## 一、视觉方向：纸雕绘本（paper-cut storybook）

一句话概括：**像一本做得很好的儿童绘本，而不是一个网站。**

| 决策 | 做法 | 为什么 |
| --- | --- | --- |
| 底色 | 暖纸白 `#FBF5EA` + 极淡网点纹理 | 纯白会产生“软件感”；纸感让画面像书 |
| 文字 | 墨色 `#2E2A25`，不用纯黑 | 纯黑在暖底上太硬 |
| 主色 | 每个领域一个**低饱和**主色（见下） | 高饱和彩虹色 = 廉价儿童网站 |
| 形状 | 大圆角（22 / 28 / 40 / 全圆） | 圆角是“没有危险”的视觉语言 |
| 阴影 | 贴纸式：短距离硬投影 + 长距离柔投影 | 制造纸片层叠的手工感，而不是 Material 的悬浮感 |
| 描边 | 2px 低对比细墨线 | 绘本插画的勾线，也是卡片之间清晰的分界 |
| 字型 | 展示字 `ZCOOL KuaiLe` / 正文 `Noto Sans SC` / 数字 `Baloo 2` | 中文标题需要圆润且有性格；数字要胖 |
| 留白 | 大量 | 密度是成人信息产品的语言 |

### 调色板（14 个领域 + 成长色）

每个色调都是**三件套**：主色 `--color-x` / 柔色 `--color-x-soft` / 深色 `--color-x-deep`。
组件通过 `toneVars(tone)` 拿到 `--tone` / `--tone-soft` / `--tone-deep` / `--tone-line` / `--tone-glow`，
**因此新增一个领域只需要在 `tokens.css` 里加一组变量，不动任何组件。**

| 领域 | 主色 | 气质 |
| --- | --- | --- |
| 语言 language | `#3F7D5B` 叶绿 | 安静、生长 |
| 阅读 reading | `#8A6A3B` 木褐 | 书页、旧纸 |
| 数学 math | `#D2833A` 陶土 | 明确、有分量 |
| 科学 science | `#2F7E8C` 湖蓝 | 冷静、清澈 |
| 艺术 art | `#C05B7E` 玫瑰 | 表现力 |
| 音乐 music | `#7A5EA8` 紫藤 | 情绪、节奏 |
| 思维 think | `#C08A1E` 芥黄 | 专注 |
| 探索 explore | `#2F6FB0` 靛蓝 | 广阔 |
| 编程 code | `#5B6ABF` 长春花 | 逻辑 |
| 生活 life | `#6E8B3D` 橄榄 | 日常 |
| 社交 social | `#D2685E` 珊瑚 | 温度 |
| 英语 english | `#3C8FA8` 青蓝 | 第二语言 |
| 劳动 labor | `#8A7B3C` 卡其 | 实干 |
| 品格 moral | `#6B7F5E` 苔绿 | 稳重 |

成长与反馈色：`star #F5B82E` · `energy #6FBF73` · `badge #B07FD4` · `success #57A773` · `gently #E9A23B` · `alert #D2685E`。

> **`gently` 是「差一点点」的颜色，不是红色。** 产品明确要求不要红叉、不要挫败感。

## 二、动效体系

### 动效令牌（`src/styles/tokens.css`）

```
时长   tap 120ms · quick 220ms · base 320ms · settle 520ms · celebrate 900ms
缓动   --ease-soft    cubic-bezier(.22, 1, .36, 1)     出场、位移
       --ease-bounce  cubic-bezier(.34, 1.56, .64, 1)  弹一下
       --ease-snap    cubic-bezier(.4, 0, .2, 1)       状态切换
```

### 反馈分级（`src/styles/animations.css` 的 `fx-*` 类）

| 类 | 用途 | 视觉 |
| --- | --- | --- |
| `fx-tap` | 任何可点元素 | 悬停浮起 2px，按下沉 1px |
| `fx-pressable` | 卡片、选项 | 悬停放大 3.5% 并轻微旋转，按下缩到 96% |
| `fx-correct` | 答对 | 弹一下 + 绿色光环扩散 |
| `fx-gently` | 差一点点 | 温柔左右摇一摇（**没有红色，没有 ✕**） |
| `fx-stagger` | 列表入场 | 子元素按 50ms 错峰浮现 |
| `fx-dragging` / `fx-drop-active` | 拖拽中 / 拖放目标 | 浮起旋转 / 高亮描边 |
| `fx-star-fly` / `fx-confetti` | 星星飞入 / 彩纸 | **仅高等级奖励使用** |

### 时机原则

- 单次反馈总时长控制在 **0.5 ~ 1.5 秒**（需求第十六节）。这不是审美偏好 —— 拖沓的动画
  会让孩子失去“我还想再来一次”的冲动。
- **动画不阻塞操作**：做对之后不会自动跳走，孩子自己点「继续」掌握节奏。
- 全站只有一处关心无障碍：`src/composables/useMotion.ts` 里的 `prefersReducedMotion()`，
  开启后所有动效直接跳过。

## 三、奖励体系

### 分级（`REWARD_TIERS`，`src/domain/growth/rewards.ts`）

| 等级 | 触发 | 星星 | 彩纸 | 角色 | 时长 |
| --- | --- | --- | --- | --- | --- |
| `tap` | 普通点击 | 0 | ✗ | ✗ | 160ms |
| `correct` | 答对一次互动 | 1 | ✗ | ✓ | 640ms |
| `task` | 完成一个任务 | 2 | ✗ | ✓ | 900ms |
| `lesson` | 完成一节课 | 5 | ✓ | ✓ | 1400ms |
| `chapter` | 完成一个章节 | 12 | ✓ | ✓ + 屏震 | 1500ms |
| `streak` | 连续学习里程碑 | 8 | ✓ | ✓ | 1500ms |

**页面不允许自己写奖励动效。** 任何地方都只能调：

```ts
const feedback = useFeedbackStore()
feedback.celebrate({ tier: 'correct', mascot: 'fox' })
```

强度、星星数、是否撒彩纸全部由 `REWARD_TIERS` 决定。
这样「不要过度奖励」（需求第二十四节）就是一条**结构性约束**，而不是每个页面各自拿捏的分寸。

### 成长语言（孩子能理解的四件事）

| 概念 | 含义 | 来源 |
| --- | --- | --- |
| ⭐ 星星 | 完成学习任务获得 | 互动星星 + 课程结算 1~3 星 |
| ⚡ 能量 | 连续学习获得 | `learningDays × 2 + streakDays × 10` |
| 🏅 徽章 | 完成特定挑战获得 | 7 枚，规则是声明式数据（`BadgeRule`） |
| 🌱 等级 | 成长阶段 | 小种子 → 小芽芽 → 小树苗 → 森林探险家 → 星图领航员 → 探索队长 → 学习世界大师 |

徽章墙**不隐藏未获得的徽章**，而是显示「还差多少」——
看得见的距离才是自驱力，藏起来只会让孩子忘了还有目标。

### 等级与星星不惩罚

连续学习断了不会扣星星、不会清零等级、不会出现「你退步了」。
隔一天再回来，只是从新的第一天重新数 —— `computeStreak` 明确实现了这一点。

## 四、角色系统

角色不是装饰。每个角色都声明了自己的**语气**（`Mascot.voice`）与**默认台词**：

| 角色 | 定位 | 默认鼓励 | 默认提示 |
| --- | --- | --- | --- |
| 🐻 熊老师 | 总在身边的老师 | 做得真好，我们一起记住了！ | 差一点点，再看一眼就好啦。 |
| 🐰 小兔 | 一起玩的小伙伴 | 哇！你比我跳得还快！ | 别急，我陪你再来一次。 |
| 🐱 小猫 | 安静观察的伙伴 | 你观察得真仔细。 | 慢慢来，答案就藏在里面。 |
| 🦊 小狐狸 | 爱出谜题的好朋友 | 又被你解开了，真厉害！ | 再想一想，你可以的。 |
| 🐼 熊猫 | 一起动手的搭档 | 我们做到了，抱一个！ | 没关系，慢慢试就好。 |
| 🚀 小机器人 | 来自太空的探索家 | 任务完成，数据已记录！ | 检测到新线索，再试一次？ |

角色在六个环节出场：**引入 · 提问 · 提示 · 鼓励 · 错误反馈 · 奖励反馈**。
孩子选择的伙伴可以在奖励中心随时更换（`profile.chooseMascot`）。

## 五、一致性检查清单

改任何一个组件前，先过一遍：

- [ ] 颜色是否来自令牌，而不是十六进制硬编码？
- [ ] 领域相关元素是否用 `toneVars(tone)` 而不是写死某个领域的颜色？
- [ ] 可点元素是否有 `fx-tap` / `fx-pressable`，并有 `hover → press` 两态？
- [ ] 是否用了红色或 ✕ 表达“错误”？（**换成 `gently` + 温柔文案**）
- [ ] 空状态是否说人话？（「还没有…，我们一起去找找」，而不是「暂无数据」）
- [ ] 奖励是否走了 `feedback.celebrate(tier)`，而不是自己写动画？
- [ ] 键盘能否操作？焦点环是否可见？装饰性 emoji 是否 `aria-hidden`？
